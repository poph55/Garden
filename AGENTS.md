# Agent Instructions

This file is the entry point for guidance used when maintaining this website.
Detailed reference documents live in [`docs/agent-guides`](docs/agent-guides).

## Required references

- For React implementation, refactoring, code review, bundle optimization, or
  end-user performance work, read
  [`docs/agent-guides/react-performance.md`](docs/agent-guides/react-performance.md)
  before making changes.

## Adding guidance

- Put substantial new reference material in `docs/agent-guides` rather than
  expanding this file.
- Give each guide a focused, descriptive filename.
- Add or update a routing entry above so agents know when the guide applies.
- Keep instructions in this file concise and repository-wide.

User and system instructions take precedence over these repository references.
